BAGAIMANA CARA MENAMBAHKAN SUARA ANDA SENDIRI?

1. Buka folder lokasi di mana file soloptik.exe berada.

2. Cari folder bernama custom_sounds/ (folder ini dibuat otomatis setelah pertama kali dijalankan).

3. Masukkan file audio favorit Anda (format .mp3, .wav, atau .ogg) ke dalam folder tersebut.

4. Refresh dashboard ini, dan suara Anda akan otomatis muncul di dropdown pilihan di atas!

BAGAIMANA CARA PASANG DI OBS STUDIO?

1. Klik tombol Copy Link pada widget yang ingin dipasang.

2. Buka OBS Studio -> Di panel Sources klik ikon + -> Pilih Browser.

3. Beri nama (misal: "SolopTik Alert") -> Klik OK.

4. Di kolom URL, hapus link bawaan dan paste link yang sudah disalin tadi.

5. Atur Width dan Height sesuai ukuran ideal di atas -> Centang "Control audio via OBS" jika ingin suara dikontrol di OBS -> Klik OK.
